= Configure SSO and external authentication
:context: configure-sso-and-external-authentication

toc::[]

[role="_abstract"]
Configure Single Sign-On (SSO) for Argo CD by using Dex or OpenID Connect (OIDC) providers. SSO integration enables centralized user authentication and simplifies access management for your Argo CD instances.

.Prerequisites
* The {gitops-title} Operator is installed on your {OCP} cluster.
* You have access to the cluster with `cluster-admin` privileges.
