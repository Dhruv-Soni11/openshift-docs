= Secure communication between GitOps components
:context: secure-communication-between-gitops-components

toc::[]

[role="_abstract"]
Secure communication between {gitops-title} components by configuring mutual TLS (mTLS) for the Argo CD Agent and TLS encryption for Redis cache connections. These configurations protect sensitive data in transit.

.Prerequisites
* You have access to the cluster with `cluster-admin` privileges.
* You have access to the {OCP} web console.
* {gitops-title} Operator is installed on your cluster.
