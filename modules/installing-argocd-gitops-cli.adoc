= Install the GitOps CLI

Use the {gitops-shortname} `argocd` CLI tool to configure and manage {gitops-title} and Argo CD resources from the command line. You can install it on Linux, macOS, and Windows.
[NOTE]
====
Both the compressed archives and the RPMs contain the `argocd` executable binary file. If you have an active {OCP} subscription on your Red Hat account, install the CLI tool as an RPM by using a package manager, such as `yum` or `dnf`.
====
