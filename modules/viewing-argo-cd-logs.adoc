= Viewing Argo CD logs

Viewing Argo CD logs helps you troubleshoot GitOps deployments and monitor application synchronization. Use the {logging-title} to access and filter Argo CD controller and application logs through the Kibana dashboard. The {logging-title} collects logs from all pods in the cluster, including {gitops-title} components.
