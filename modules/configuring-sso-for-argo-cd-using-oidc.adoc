= Configuring SSO for Argo CD using external OIDC providers

After the {gitops-title} Operator is installed, Argo CD automatically creates a user with `admin` permissions. To manage multiple users, cluster administrators can use Argo CD to configure Single Sign-On (SSO) with external OpenID Connect (OIDC) providers.

Before configuring OIDC, ensure that you have:

* Configured an OIDC-compliant identity provider according to the provider's official documentation.
* Obtained the following information from your OIDC provider:
** Issuer URL
** Client ID
** Client secret
