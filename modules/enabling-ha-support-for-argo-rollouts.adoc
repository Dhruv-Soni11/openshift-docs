= Configure HA for Argo Rollouts

Argo Rollouts supports high availability (HA) through the `RolloutManager` custom resource (CR). When HA is enabled, the Operator sets the controller pod count to 2 using the `.spec.ha` field and activates leader election for active-passive operation.
