= Monitor Argo CD health and performance
:context: monitor-argo-cd-health-and-performance

toc::[]

[role="_abstract"]
Monitor the health and performance of your Argo CD instances and the {gitops-title} Operator. You can access monitoring dashboards, track Prometheus metrics, and configure monitoring for Argo CD custom resource workloads.

.Prerequisites
* You have access to the cluster with `cluster-admin` privileges.
* You have access to the {OCP} web console.
* You have installed the {gitops-title} Operator in your cluster.
