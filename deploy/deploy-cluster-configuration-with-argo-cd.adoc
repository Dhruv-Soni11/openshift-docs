= Deploy cluster configuration with Argo CD
:context: deploy-cluster-configuration-with-argo-cd

toc::[]

[role="_abstract"]
Deploy and manage {OCP} cluster configuration declaratively by using Argo CD. You can synchronize cluster settings from a Git repository and configure permissions for cluster-scoped resources.

.Prerequisites
* You have logged in to the {OCP} cluster as an administrator.
* You have installed the {gitops-title} Operator on your {OCP} cluster.
