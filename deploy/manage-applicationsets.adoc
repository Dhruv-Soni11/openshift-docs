= Manage ApplicationSets
:context: manage-applicationsets

toc::[]

[role="_abstract"]
Manage ApplicationSets to automate the deployment of multiple Argo CD applications across clusters and namespaces. ApplicationSets enable you to generate and manage applications declaratively from a single repository.

.Prerequisites
* You have a user-defined xref:../deploy/deploy-cluster-configuration-with-argo-cd.adoc#using-argo-cd-instance-to-manage-cluster-scoped-resources_deploy-cluster-configuration-with-argo-cd[cluster-scoped Argo CD instance] in your defined namespace. For example, `spring-petclinic` namespace.
* You have xref:../deploy/manage-applications-across-namespaces.adoc#managing-apps-in-non-control-plane-namespaces[explicitly enabled and configured] the target namespaces in the `ArgoCD` CR to manage application resources in non-control plane namespaces.
