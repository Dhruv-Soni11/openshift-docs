= Manage applications across namespaces
:context: manage-applications-across-namespaces

toc::[]

[role="_abstract"]
Manage Argo CD applications across multiple namespaces on your {OCP} cluster. You can deploy applications in non-control plane namespaces and configure application links by using the `managed-by-url` annotation.

.Prerequisites
* You have installed {gitops-title} 1.13.0 or a later version on your {OCP} cluster.
* You have a user-defined xref:../deploy/deploy-cluster-configuration-with-argo-cd.adoc#using-argo-cd-instance-to-manage-cluster-scoped-resources_deploy-cluster-configuration-with-argo-cd[cluster-scoped Argo CD instance] in your defined namespace, for example, `spring-petclinic` namespace.
