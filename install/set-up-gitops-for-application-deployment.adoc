= Set up GitOps for application deployment
:context: set-up-gitops-for-application-deployment

toc::[]

[role="_abstract"]
Set up {gitops-title} on your {OCP} cluster by installing the Operator and the `argocd` CLI tool. After installation, you can deploy and manage applications using Argo CD.

.Prerequisites
* You have access to the {OCP} web console.
* You are logged in to the {OCP} cluster as an administrator.
* Your cluster has the Marketplace capability enabled or the Red Hat Operator catalog source configured manually.

[WARNING]
====
If you have already installed the Community version of the Argo CD Operator, remove the Argo CD Community Operator before you install the {gitops-title} Operator.
====
