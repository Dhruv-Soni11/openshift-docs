= Understand and set up Argo Rollouts
:context: understand-and-set-up-argo-rollouts

toc::[]

[role="_abstract"]
Understand and set up Argo Rollouts for progressive deployment delivery on {OCP}. Argo Rollouts simplifies canary and blue-green deployments by allowing application teams to define rollout strategies declaratively.

.Prerequisites
* You have access to the cluster with `cluster-admin` privileges.
* You have access to the {OCP} web console.
* {gitops-title} 1.9.0 or a newer version is installed on your cluster.
