= Customize the GitOps console
:context: customize-the-gitops-console

toc::[]

[role="_abstract"]
Customize the {gitops-title} console experience by configuring the `GitOpsService` custom resource and the GitOps console plugin. The console plugin extends the {OCP} web console with views for Argo CD applications, ApplicationSets, AppProjects, and Argo Rollouts.

.Prerequisites
* You have access to {OCP} 4.19 or later.
* You have installed the {gitops-title} Operator.
