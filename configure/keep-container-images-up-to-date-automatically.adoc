= Keep container images up to date automatically
:context: keep-container-images-up-to-date-automatically

toc::[]

[role="_abstract"]
Keep container images up to date automatically by using the Argo CD Image Updater. The Image Updater monitors container registries for new image versions and updates Argo CD applications when versions matching your constraints are found.
